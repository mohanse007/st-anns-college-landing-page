# St.Ann's College for Women - Landing Page

A premium, modern, and conversion-focused landing page built with React, TypeScript, Tailwind CSS, and Framer Motion.

## ✨ Features

- **Premium Design**: Clean typography, generous whitespace, refined gradients, and subtle glassmorphism
- **Smooth Animations**: Scroll reveals, staggered entrances, hover effects, ambient motion, and interactive microinteractions
- **Complete Structure**: 
  - Sticky navigation bar
  - Hero section with animated elements
  - Social proof with statistics
  - Feature highlights
  - Programs showcase
  - Campus facilities
  - Student testimonials
  - Admissions process & pricing
  - FAQ section
  - Call-to-action
  - Comprehensive footer

## 🎨 Design Highlights

- **Modern Aesthetics**: Gradient backgrounds, glassmorphic cards, and premium color scheme (Purple & Pink)
- **Responsive**: Mobile-first design that works perfectly on all devices
- **Accessible**: Semantic HTML, proper contrast ratios, and keyboard navigation
- **Performance**: Optimized animations and lazy loading for smooth performance

## 🚀 Technologies Used

- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion (animations)
- Lucide React (icons)
- Vite (build tool)

## 📦 Components

1. **Navbar** - Sticky navigation with smooth transitions
2. **Hero** - Eye-catching hero section with floating animations
3. **SocialProof** - Statistics and trust indicators
4. **Features** - Six key features with hover effects
5. **Programs** - Academic programs with detailed cards
6. **Benefits** - Campus facilities showcase
7. **Testimonials** - Alumni success stories
8. **Admissions** - Application process and pricing plans
9. **FAQ** - Accordion-style frequently asked questions
10. **CTA** - Final conversion section
11. **Footer** - Comprehensive footer with links and contact info

## 🎯 Conversion Optimization

- Clear call-to-action buttons throughout
- Trust indicators (NAAC A+, placement rates)
- Social proof (testimonials, alumni network)
- Simplified admission process
- Transparent pricing
- FAQ to address concerns
- Multiple contact methods
